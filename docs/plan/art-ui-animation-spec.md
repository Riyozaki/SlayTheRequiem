> Часть [плана доделки](completion-plan.md) (вехи M1, M3, M6, M7). Опирается на дизайн 01 (тон), 02 §6 (UI ресурсов),
> 03 (стихии), 06 §5 (формы), 07 §8 (кукла и цвета ступеней), 13 §4.2 (значки карты), `tech/technical-plan.md` §7.
> Полный поимённый список файлов — [asset-manifest.csv](asset-manifest.csv). Его генерирует
> `python3 tools/assets/asset_manifest.py --csv docs/plan/asset-manifest.csv`; флаг `--check` возвращает 1, пока чего-то не хватает.

## 0. Главное правило: сначала ванильный арт

Решение владельца (2026-11): **~1500 своих картинок не будет.** Каждая модель мода показывает подобранный ванильный арт, а свой
файл, положенный по пути модели, автоматически его перекрывает. Свой арт рисуется только там, где ванильного по смыслу нет.

**Цепочка выбора картинки** (`Extensions/StringExtensions.cs`, `Art/VanillaArt.cs`), для каждого вида модели:
1. **Свой файл** мода по стандартному пути (§3) — если он есть в паке (`ResourceLoader.Exists`, результат кэшируется).
2. **Ванильный** арт из таблицы `Art/VanillaArtTable.g.cs` — путь строится так же, как в игре (`ImageHelper`, атласы
   `card_atlas` / `power_atlas` / `relic_atlas`, `events/`, `enchantments/`), с проверкой существования.
3. **Заглушка** шаблона (`card.png`, `power.png`, `relic.png`) — в норме не встречается: CI требует 0 пробелов.

**Таблица подстановки — `tools/art/vanilla_art.csv`** (`kind,mod,vanilla,note`, строки `#` — комментарии):
- `kind`: `card`, `power`, `relic`, `event`, `enchantment`. `mod`: имя класса мода или шаблон `*?[` (сначала применяются
  шаблоны — первый подходящий, затем точные имена их перекрывают). `vanilla`: для карт `пул/Класс` (`silent/BouncingFlask`),
  для остального — имя ванильного класса.
- Подбор по смыслу: атака — атака, щит — защита, яд — яд, мороз — мороз. Предпочтение — артам **Некробиндера и Дефекта**:
  их персонажи скрыты (06 §4), поэтому арт не примелькался. Нельзя брать ванильные модели с переопределённым
  `PortraitPath` (MadScience, LoomingFruit, YummyCookie) — их путь не строится по общим правилам.
- `python3 tools/art/build_vanilla_art.py` проверяет таблицу по снимку ванильных моделей (`tools/art/vanilla_models.txt`,
  v0.107.1, 1211 моделей; обновляется `snapshot_vanilla.py <decompiled> <версия>`) и по классам мода, затем пишет
  `VanillaArtTable.g.cs`. Флаг `--check` (в CI) падает, если таблица устарела, есть ошибки или модель без картинки.
- `python3 tools/art/art_fit.py --check` (в CI, M3 п. 3 — то, что видно без игры): у карты боя портрет того же **типа**
  (атака/навык/сила — по `vanilla_card_types.txt`), и **не дубль** — не с ванильной карты, которую герой Реквиема видит в
  забеге (пулы Ironclad/Silent/Regent/бесцветных, кроме изъятых 19 §2, и карты, открытые трансформациями 19 §4).
  Арт изъятых карт (StoneArmor, KinglyPunch, HowlFromBeyond…) свободен. Исключение — note «тип: …» или
  «дубль: …» с причиной (сейчас 14 «тип:», все — буквальное совпадение смысла: Zap — искра, Storm — гроза).
- Сейчас покрыто всё: 283 карты, 104 силы, 154 реликвии, 9 событий, 6 чар; зелья — ванильные бутылки (`Potions.cs`),
  лагерь — ванильные иконки, враги — ванильные облики.

**Свой арт — только это:**

| Что | Статус | Где |
|---|---|---|
| ◆ ✦ ⚖, фон цены ◆, значок веса | ✅ векторно | `art/ui` → `images/ui` |
| 8 типов урона, намерения «Передышка» и «Заклинание», силуэт куклы | ✅ векторно | `art/ui` → `images/ui` |
| 20 значков карты (13 §4.2) | ✅ векторно | `art/map/icons` → `images/map/icons` |
| Компоненты UI (шкалы, значок цены, панель Груза, кукла) | M1 — сцены Godot из этих значков | §4 |
| Табличка служебных жетонов и 8–10 эмблем | M1–M3 | §3.1 |
| Супербоссы, фоны актов | по желанию, M7 | §3.9–3.10 |
| UI героев и происхождений | по желанию, если ванильное не подойдёт | §3.11 |

Векторные исходники (SVG) лежат в `art/` — вне Godot-проекта, чтобы движок их не импортировал. PNG собирает
`tools/art/render_ui_icons.mjs` (resvg): `npm i --prefix /tmp/r @resvg/resvg-js@2 && NODE_PATH=/tmp/r/node_modules node tools/art/render_ui_icons.mjs`.
Три состояния значков карты (обычный, пройденный, доступный) задаются тонировкой `Modulate`, как у ванильных, — отдельных файлов нет.

Остальные разделы описывают требования **на случай своего арта** — если владелец решит заменить отдельную ванильную картинку.

## 1. Арт-дирекция

- **Как ванильный StS2.** Рисованная живопись с толстым тёмным контуром, 2–3 тона на объект и читаемый силуэт.
  Мод должен выглядеть «как будто его сделала Mega Crit», а не как Скайрим в рамке.
- **Тон: мрачно-ироничный** (01). Без пафосного high-fantasy, без фотореализма и без 3D-рендеров.
- **Никаких узнаваемых TES-символов** (01 «Никаких имён из TES»). Нельзя: имперский дракон, даэдрический алфавит, конкретные гербы владений,
  узнаваемые лица NPC. Можно: архетипы (норд-подобный воин в мехах, ящер, кот, тёмный эльф) в стилизации Шпиля.
- **Читаемость в размере.** Иконки проверяются в 64×64 и 32×32 на тёмном и светлом фоне. Портреты карт — в малом превью 250×190.
- **Генерация концептов допустима, финал — ручная доработка** под стиль (tech §7). Для каждого ассета храним исходник (PSD/KRA) и
  лицензию. Нейросетевой финал без доработки в релиз не идёт.

## 3. Спецификации по видам

### 3.1 Портреты карт

- **Файлы:** `images/card_portraits/big/{id}.png` 1000×760 (основной арт, `CustomPortraitPath`) и
  `images/card_portraits/{id}.png` 250×190 (малый, `PortraitPath`). Можно положить `beta/{id}.png` (эскизная версия, как в ванили).
  Размеры совпадают с заглушками шаблона.
- **Композиция:** главный объект в центральных 70 %, верх и низ уходят под рамку. Безопасная зона — по 12 % сверху и снизу.
- **По типу:** Атака — действие и удар (оружие, траектория, вспышка стихии по типу урона). Навык — поза, щит, жест, предмет.
  Сила — символ или аура, статичная сцена. Клич — открытый рот или волна звука, кольца. Заклинание — руки и печать школы, цвет школы.
- **Пулы:** Латоносец — сталь, мех и иней, холодная гамма. Безмолвная — зелень и фиолет, полутень. Регент — золото и звёзды.
  Пути и формы — цвет формы (вампир — алый, оборотень — бурый, праведник — белое золото, Лич — костяной зелёный).
- **Служебные жетоны** (147, список — `card-catalog.md`, строки без типа карты): портрета нет. Рамка «табличка/свиток» и эмблема категории 256×256. Реализация — через одну общую
  картинку категории (переопределение `PortraitPath` в базовом классе жетонов) и стиль рамки (card spec §5).
- **Именование:** `{id}` = snake_case имени класса (`AgainstAllOdds` → `against_all_odds`) — так строит `RequiemCard`.

### 3.2 Реликвии и снаряжение

- `images/relics/{id}.png` 94×94, `images/relics/{id}_outline.png` 94×94 (белый контур 2–3 px по альфе), `images/relics/big/{id}.png` 256×256.
- Снаряжение рисуется **как предмет**, а не как персонаж: оружие по диагонали, броня — фронтально. Цвет ступени — §1.1.
- Комплекты (Железо ополченца, Шкуры загонщика, Кольчуга контрабандиста) — единая палитра и общий мотив на всех 4 частях.
- Служебные реликвии (Дорожная карта, Котомка, Летопись героя, Камень Памяти, Бирка лавки) — свиток, мешок, книга, камень, бирка.
- Небесные (30) и Князья (8) — эмблемы-печати: Небесные — белое золото с лучами, Князья — красно-чёрный сургуч.
  Знамения (10) — созвездия на тёмно-синем.

### 3.3 Силы (статусы)

- `images/powers/{id}.png` 64×64 и `images/powers/big/{id}.png` 256×256, RGBA.
- Конвенция ванили: бафф — тёплая или нейтральная гамма, дебафф — холодная или зелёная с тёмным контуром. Стихийные статусы — цвет типа урона (§1.1).
- Обязательно различимы попарно: Шаткость и Слом, Устал и Изнурён, Озноб и иммунитет к заморозке, Яд и Мор.

### 3.4 Зелья

- `images/potions/{id}.png` и `images/potions/outline/{id}.png`. Размер — как у ванильных зелий (взять из распакованного `.pck`
  игры через GDRE Tools: `res://images/potions/*`). Пока картинок нет, используется ванильная бутылка (`VanillaArt`).
- 24 силуэта бутылок по семействам (`Brew`). Ступень — 1/3/5 насечек на горлышке и насыщенность жидкости. Яды — бутылка с черепом-пробкой.

### 3.5 События

- `images/events/{id}.png`. Размер и композиция — как у ванильных событий (сверить по `.pck`). Сцена, без UI.
- Нужно 9 сейчас + ~24 по плану M5. Атмосфера акта события: Курганы — лёд и склепы; Глубины — медь и пар; Двор — бархат и кровь;
  Башня — звёзды и стекло.
- ✅ **M5 п. 3:** 30 событий актов — свои картинки `images/events/{id}.jpg` 1720×807 (JPG, как фоны актов). Генератор
  `tools/art/events/build_events.py`: 6 фонов (Курганы, Глубины, Двор, Башня, янтарь Улья, руины Славы с трещинами Бездны) +
  свой мотив события по центру; SVG-исходники в `art/events/`, CI сверяет их с генератором (`--check`). 9 событий Пантеона и форм
  пока на ванильных портретах (vanilla_art.csv).

### 3.6 Иконки интерфейса

`images/ui/`: `stamina.png`, `mana.png`, `burden.png`, `stamina_cost_orb.png` (фон значка цены ◆),

`slots/paper_doll.png`. Размер 64×64 (иконки) и 128×128 (крупные), RGBA, контур 3 px.
✅ Все 16 нарисованы векторно (§0); ресурс ◆ берёт `images/ui/stamina.png`, при отсутствии — картинку мода (R-22).

### 3.7 Лагерь

`images/ui/rest_site/option_{option}.png` — 12 действий мода: Короткий отдых, Варка, Готовка, Кузня, Зачарование, Зачарование карт,
Медитация, Молитва, Тренировка, Сундук, Обряды зверя, Отогреться. Размер — как у ванильных иконок лагеря. Сейчас — ванильные `FallbackIcon`.

### 3.8 Значки карты (13 §4.2)

`images/map/icons/*.png`, 64×64, стиль чернил, толстый контур. 20 значков: ☀ Святилище, ⛧ Тёмный алтарь, ⚒ Оружейник,
✧ Чародейская лавка, ⚗ Травница, ◈ Ювелир, 🐪 Караван, 🗝 Скупщик, 🍺 Таверна, 📖 Библиотека, 🐾 Логово, ⚔ Испытание, ⚿ Тайник,
⛓ Запертые врата, ⚙ Вентиль, ◉ Врата Бездны, ✹ Багровый портал, ◇ Камень Памяти, ≈ Камни отлива, ! Засада.
Подтипы лавок различаются **силуэтом над прилавком**: молот, звезда, колба, кольцо, верблюд, ключ. У каждого значка 3 состояния:
обычный, пройденный (приглушённый) и доступный (подсветка).
✅ Все 20 нарисованы (§0): чернильный силуэт + цвет группы; лавки — силуэт над общим прилавком. Состояния — `Modulate`.

### 3.9 Враги

- Технология как в игре: Spine (`MegaSprite`, `CreatureAnimator`). Сцена `NCreatureVisuals` (`.tscn`) указывается через
  `CustomVisualPath`, состояния — через `SetupCustomAnimationStates` или `CustomMonsterModel.SetupAnimationState` (недостающие
  анимации падают в Idle). Конвенция BaseLib по умолчанию: `res://scenes/creature_visuals/{modname}-{class_name}.tscn`.
- **Минимальный набор анимаций:** Idle (loop), Attack, Cast (для магов и колдунов, у ✦-врагов обязательно), Hit, Dead.
  Для супербоссов добавляются Phase2 (переход фазы) и Special (уникальный приём).
- **Порядок:** 8 супербоссов со свитой и Рыцарь-эхо (17 существ, `Monsters/Superbosses.cs`), затем 7 редких элит, потом обычные элиты актов 2а, 2б, 4а, 4б,
  оверлеев и Бездны. Фракции: Курганные мертвецы, Заводные стражи, Береговые грабители, Кровавый двор, Отступники Башни,
  Порождения Бездны, Культ Безликих (13 §2) — общая база рига и перекраска.
- **Боссы актов 2 и 4 (M5, сделано):** вместо Spine — статичный PNG с прозрачным фоном и код-анимацией (`OwnArtMonster`/`OwnArtAnimator`:
  Idle — дыхание, Attack — выпад, Hit — вспышка и тряска, Cast — свечение, Dead — растворение 0.9 с, фаза — смена картинки со вспышкой).
  Холст варианта (`_p2`, `_night`) совпадает с основным, низ фигуры — у нижнего края. Стиль: толстый контур `#120d14`, свет слева сверху,
  контровой свет цвета акта, светящиеся глаза и руны, зерно. Исходники — `tools/art/monsters/draw_monsters.py` → `art/monsters/*.svg` →
  `render_ui_icons.mjs`; значки карты — `build_boss_icons.py`. 12 боссов × 2 + 4 вида свиты = 28 спрайтов (галерея: `img/m5-bosses.jpg`).
- До своих визуалов сохраняется `LookOf` (облик ванильного врага); в манифесте указано, чей облик используется.

### 3.10 Фоны актов

## 7. Пайплайн

1. **Хранение исходников:** PSD/KRA и Spine-проекты — вне основного Git (облако или отдельный репозиторий с LFS). В основной
   репозиторий попадают только экспортированные PNG и сцены. Если PNG станет больше ~200 МБ — включить Git LFS для `mod/SlayTheRequiem/images/**`.
2. **Экспорт:** векторные значки — `tools/art/render_ui_icons.mjs` (§0). Для растрового арта (если появится) —
   `tools/assets/export.py` (предлагается): даунскейл 1000×760 → 250×190, 256 → 94 и 64, генерация `_outline` по альфе.
3. **Проверки:** `asset_manifest.py --check` и `build_vanilla_art.py --check` — блокирующие шаги CI. Манифест считает картинку
   закрытой, если есть свой файл (`own`) или строка ванильной таблицы (`vanilla`); сейчас own 36, vanilla 1432, нет 0.
4. **Godot-импорт:** UI и иконки — без mipmaps, фильтр Linear, сжатие Lossless. Портреты — VRAM Compressed допустимо (сверить с ванилью).
5. **Именование:** только snake_case `{id}` из манифеста. Ручных имён не бывает: код строит путь сам.
6. **Ревью арта:** в PR — скриншот в игре (рука, подсказка, панель реликвий) рядом с ванильным аналогом.
