# Дорожная карта

## Этап 0 — Подготовка (1–2 недели)
- [ ] Развернуть `Alchyr/ModTemplate-StS2` в `src/`, подключить BaseLib, собрать «пустой» мод, проверить загрузку.
- [ ] CI: сборка на push (без игры — против заглушки/референс-сборок, если лицензия позволяет; иначе локальная).
- [ ] Debug-команды `str_*`, конфиг с модулями.
- [ ] `data/` + генератор локализации.

## Этап 1 — Вертикальный срез «Латоносец, акт 1» (3–5 недель)
Цель: проверить, **весело ли с выносливостью и Латами**.
- [ ] Выносливость: шкала, цены атак, Устал/Изнурён, UI.
- [ ] Типы урона, Латы, Пробитие, Раскол, сопротивления (DamagePipeline + тесты).
- [ ] Статусы: Горение, Озноб, Кровотечение.
- [ ] Латоносец: 1 происхождение (Инеерождённые) × 3 предыстории, 20 новых карт.
- [ ] Снаряжение: слоты оружия/щита/тела, 10 предметов I–II ступени.
- [ ] Враги акта 1: ◆ у врагов, 3 аффикса, элита «Атаманша Багряных Ножей».
- [ ] Плейтест: 10 забегов, анкета «понятно / весело / скучно».

**Критерий выхода:** выносливость ощущается как выбор, а не налог; Латы ощутимо меняют бой против роя.

- [ ] Враги-маги с ✦; элита «Хранитель Гробницы».

## Открытые вопросы

1. **Выносливость для ванильных карт:** правило `◆ = max(1, энергия)` или ручная разметка всех ~300 ванильных атак? (Старт — правило + ручные исключения.)
2. **Мана у Латоносца/Безмолвной:** нужна ли вообще, или заклинания им доступны только через свитки? (Модуль конфига; решим по плейтесту.)
3. **Кукла снаряжения:** полноценная смена спрайтов дорога — MVP только оружие/щит.
4. **Некробиндер и Дефект:** включать ли их в систему (◆/✦/груз по умолчанию) или оставить ванильными с совместимостью?
5. **Метапрогресс лагеря:** включать по умолчанию или только опцией?
6. **Реакции стихий:** оставить опцией или сделать ядром, если плейтест покажет, что они понятны.
