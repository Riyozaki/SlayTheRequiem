# Б2.3 — функциональные экраны, исходниковый checkpoint 18.11.2026

**Статус: реализация в исходниках + доступная автоматика, не игровая приёмка.**
В этой среде нет .NET SDK/легальных `sts2.dll`/`0Harmony.dll`/MegaDot. Core CI проверяет только `Core/`;
проверки грамматики/Harmony-целей не компилируют UI/Rules/Powers и не подтверждают layout в Godot.
Ручные, визуальные, контроллерные и двухклиентные прогоны — в конце релизного цикла, как решил автор.

## Что изменено

- Лист **Герой · H / нажатие левого стика**: фактический владелец, уровень/очки, ресурсы, вложения, происхождение/
  предыстория; все доступные герою ветки и узлы с ценой и причиной недоступности; школы/состояние заклинаний;
  каждый физический предмет с весом, состоянием и слотом; Груз/сундук; вера/форма/Путь; полка Кличей; боевые статусы.
  Лист не тратит очки навыков сам: обучение выполняется через лагерь и существующие `HeroRecord`-операции.
- Надеть/снять вне боя — новая `ChangeEquipment=29` в общем `ShopOperations`, с владельцем/instance key, ревизией,
  lease, digest и сетевыми квитанциями. Снятая вещь продолжает весить. `DisplacedIndices` не смешивает одинаковые кольца.
- Окно чтения: перенос длинного текста, focusable read-only строки, прокрутка за фокусом и Page Up/Down / правым
  стиком; обновление сохраняет фокус/позицию. Пока действие ожидается, отключены **все** кнопки, включая вкладки и
  закрытие; Escape/B не закрывает занятую операцию. Teardown забега закрывает только вид, не «отменяет» мутацию.
- Лагерь: категории/видимые очки и цены, полные native-кнопки в прокручиваемой сетке, пространственные соседи и
  показ фокусной строки. Кнопки остаются прямыми детьми native `_choicesContainer`: synchronizer/disable/hover/
  selection не подменены. Заголовок и scrollbar — соседи, чтобы native refresh не удалил их вместе с кнопками.
- Мастер/обучение/услуги: полные текстовые строки вместо сжатого ряда служебных карт; отмена только для необязательных
  решений. CampMenu использует native choice-ID stream на всех peers; локальная лавка отправляет только выбранную
  authoritative операцию. Временные модели убираются в `finally`.
- Услуги показывают и недоступные по золоту предложения. Продажа не обрезает длинный список: scroll, вес/выручка,
  preview при фокусе. **I / нажатие правого стика** переводит в управляющие действия лавки/награды, B возвращает назад.
- Награда: компактный боковой вес/вместимость, отдельные подробности каждой фактической модели с причиной отказа,
  описанием/миниатюрой и отдельная разгрузка. Native skip не заменён подтверждением или скрытым default.
- Полка в бою: миниатюры **тех же физических карт**, сроки; `↩` означает ожидающий повтор возврата, не Exhaust.
  Бар ничего не переносит. Все черты врага переносятся на следующие строки; native status row следует за их высотой.
  В листе боя есть полные native HoverTips и объяснение Раскола/True/cap/Блока.
- Генератор `loc_journal.py`: RU/EN, включая конечные наборы веток/слотов/состояний каста. `check_loc.py` проверяет
  полные dotted literals в shops/rewards и все динамические journal enum families, а не только одну совпавшую маску.
  Есть негативные тесты на пропавший перевод и разные параметры RU/EN.

## Совместимость и дополнительный боевой фикс

**Не смешивать версии:** saved creation protocol остаётся **2**, save schema **4**. Session/lobby agreement — **3**
(другой поток выбора лагеря + equipment action), shop protocol — **2**. Build metadata/tooling обновлены одновременно.
Старый creation draft протокола 2 не объявляется legacy только из-за нового UI. Старый shop metadata мигрируется с
backup существующим механизмом; все клиенты одной сессии должны обновиться вместе. Это требует финальной сетевой проверки.

Status ward теперь принадлежит одному native Apply/ModifyAmount frame (`PowerDefensePipeline`): veto, вложенное
наложение или исключение до уведомления освобождает только его reservation. Добавлены **не исполненные здесь** native
fixtures вложенной отмены и authority/instance-equipment. Предыдущий combat checkpoint `9ddf714` имел Core **694/694**,
но общий CI `44243765460` был FAILURE из-за устаревшего Python-assertion `Dodge(Owner)`. Он заменён проверкой captured /
deferred `Dodge(owner)`; локально **151/151** Python-тестов снова проходят. Это не ретест реального Уворота в игре.
