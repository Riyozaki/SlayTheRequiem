# 10. Лагерь (костёр) и Выживание

Ванильный костёр предлагает Отдых или Улучшение (+реликвийные опции). В моде **лагерь** — центр ремесла,
а **ветка Выживания** определяет, сколько действий там доступно.

## 1. Очки лагеря

- Каждый привал даёт **2 очка лагеря** (ванильное «одно действие» ≈ 2 очка).
- Действия стоят 1–2 очка. Неистраченные очки сгорают.
- Перки Выживания добавляют очки и новые постройки.

| Действие | Цена | Эффект |
|---|---|---|
| **Отдых** | 2 | лечит 30 % макс. ♥ (как ваниль); снимает «Усталость похода» |
| **Короткий привал** | 1 | лечит 15 % ♥ |
| **Улучшить карту** | 2 | ванильный Smith |
| **Кузня** | 2 | улучшить снаряжение +1 (07) |
| **Варка** | 1 | сварить 1 зелье/яд из реагентов (09) |
| **Зачарование** | 2 | наложить чары (нужен Камень душ) |
| **Готовка** | 1 | приготовить еду (см. 3) |
| **Молитва** | 1 | у алтаря: сменить благословение на бога лагеря / искупление (раз в акт) |
| **Сундук** | 0 | положить/забрать вещи (груз, 02) |
| **Медитация** | 1 | +1 к ступени ✦ или ◆ до конца следующего боя |

## 2. Ветка «Выживание» (общее дерево, очки навыков)

Источник — дерево Выживания RFAB (готовка, отдых, торговля, акклиматизация). 3 яруса × 3 узла.

| Ярус | Узел | Эффект |
|---|---|---|
| I | **Походный котёл** | открывает Готовку |
| I | **Ловкая укладка** | +4 груза; Сундук лагеря |
| I | **Первая помощь** | Короткий привал лечит 20 % вместо 15 % |
| II | **Опытный путник** | +1 очко лагеря |
| II | **Акклиматизация** | сопр. холоду и огню I вне боя → в бою первые 2 хода |
| II | **Торговое имя** | репутация у торговцев: цены −10 %, +1 товар в магазине |
| III | **Отдохнувший** | после Отдыха: «Бодрость» — +1 прирост ◆ и ✦ на 2 следующих боя |
| III | **Мастер привала** | +1 очко лагеря (итого 4); Кузня/Зачарование стоят 1 |
| III | **Знаток трав** | реагенты с врагов ×2; Варка ступенью выше |

## 3. Еда

- Одна **Сытость** за раз (Хмельной Князь — две). Длится **3 боя**. Готовится из реагентов + мяса (падает со зверей).
- Еда — главный способ поднять приросты ◆/✦ без снаряжения.

| Блюдо | Эффект (3 боя) |
|---|---|
| Похлёбка из кровяного мха | +6 макс. ♥ |
| Жаркое из оленины | +1 прирост ◆ |
| Рыбный суп с синецветом | +1 прирост ✦ |
| Пряная колбаса | сопр. холоду I, +2 ◆ в начале боя |
| Грибная похлёбка (Отшельник) | Регенерация 1; совместима с любой другой едой |
| Сладкий рулет | 1-й ход каждого боя +1 карта |
| **Пир** (5 реагентов) | всё перечисленное, но 1 бой |

## 4. Усталость похода (опциональный модуль)

- Каждые 3 узла карты без Отдыха → стак «Усталости»: −1 пул ◆ (макс. −3).
- Снимается Отдыхом, событиями «Таверна», едой «Пир».
- Включается на Реквиеме 5+ (сложность, см. 11).

## 5. Постройки лагеря (метапрогресс между забегами — опционально)

Если метапрогресс включён (StS2-style unlocks), за победы открываются постройки, доступные во всех будущих забегах:
**Котёл → Наковальня → Зачаровальный стол → Алтарь → Палатка травника**.
По умолчанию в забеге доступны Отдых/Улучшение/Сундук, остальное — через ветку Выживания и находки
(«Переносная наковальня» — реликвия рюкзака весом 3).

## 6. Вьючный зверь

Событие «Брошенный мул» (акт 1–2) или покупка у торговца (120 золота). Зверь — «реликвия-компаньон» без слота:
- +10 груза; Сундук лагеря доступен **в любом узле карты**, а не только у костра;
- в бою не участвует; если в событии «Засада» не защитить его (выбор), он погибает и половина содержимого Сундука теряется;
- улучшение у Отца Наковальни/кузни: «Подкованный» (+5 груза).

## 7. Визуал
Сцена костра расширяется: слева палатка, справа наковальня/стол/алтарь появляются по мере открытия.
Каждое действие — иконка-кнопка с ценой в очках (костры-«угольки» внизу экрана).
