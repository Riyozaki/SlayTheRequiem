# 15. Смерть и откат: Камень Памяти

> «Шпиль поёт Реквием по каждому павшему. Но камень у подножия каждого яруса помнит твоё имя.»

Пять актов — это долго. Терять час забега из-за одной ошибки в 4-м акте обидно, но и бесконечные перезагрузки убивают рогалик.
Решение — **ограниченный откат к началу акта** с ценой и без возможности «перебирать рандом».

## 1. Как работает

1. **Отпечаток.** В начальном узле каждого акта — **Камень Памяти**. Когда вы покидаете этот узел (после Нео/Святилища/Древнего),
   игра автоматически сохраняет **Отпечаток**: колода, реликвии, снаряжение, золото, ♥, зелья, реагенты, уровень и очки,
   праведность, благословения, трансформации, доверие торговцев, счётчики Обетов.
2. **Смерть.** Когда герой умирает (соло) или **погибает весь отряд** (кооп), на экране поражения появляется кнопка
   **«Вернуться к Камню Памяти»** — если у вас есть **Свечи Реквиема**.
3. **Возврат.** Отпечаток восстанавливается, вы снова в начальном узле акта, но:
   - **карта акта и содержимое узлов генерируются заново** (новое зерно) — заучить «где был хороший сундук» нельзя;
   - **босс и супербосс акта остаются прежними** — честно: вы знаете, к чему готовиться;
   - вы получаете **Шрам** (см. 3) и **Память о смерти** (см. 4).

## 2. Свечи Реквиема (число попыток)

| Уровень «Реквием» | Свечей за забег |
|---|---|
| 0 «Странник» | ∞ |
| 1–4 | 3 |
| 5–7 | 2 |
| 8–9 | 1 |
| 10 «Проклятый» | 0 — классический рогалик |

- Дополнительная Свеча: победа над супербоссом (+1, максимум 1 за забег) или редкое событие «Свеча в склепе».
- Настройка мода позволяет выставить своё число (в т. ч. «всегда 0» для пуристов).

## 3. Цена возврата — Шрам

При возврате выберите **одну из трёх** цен (видны заранее на экране поражения):

| Шрам | Эффект (до конца забега) |
|---|---|
| **Шрам плоти** | −6 % макс. ♥ (складывается) |
| **Шрам души** | в колоду добавляется проклятие «Предсмертное эхо» (вес 2, неиграбельно; удаление ×2 цены) |
| **Шрам кошелька** | −40 % текущего золота Отпечатка |

## 4. Память о смерти — утешение

- **Месть:** до конца повторной попытки акта ваши атаки и заклинания наносят **+10 %** урона врагам той фракции/того босса, что вас убил.
- **Опыт поражения:** сохраняется **50 % Славы**, набранной в неудачной попытке (уровни растут быстрее).
- **Знание:** намерения убившего вас босса показываются на 1 ход вперёд в повторном бою.

## 5. Кооператив

- Отдельная смерть игрока в коопе — по ванильным правилам совместной игры (откат не нужен).
- Если **весь отряд** погиб в одном бою — хост видит кнопку отката, остальные голосуют (большинство; при равенстве — хост).
- Свечи общие для отряда. Шрам выбирает каждый игрок для себя.
- Отпечаток хранит состояние всех игроков; восстанавливается только хостом и рассылается остальным.

## 6. Защита от злоупотреблений

- Отпечаток делается **только** в Камне Памяти. Выход в меню, «сохранить и выйти», сдача забега — **не** создают и не используют Отпечаток.
- Откат невозможен вручную — только с экрана поражения.
- Сдача (Abandon) забега завершает его как обычно.
- В истории забега и на экране итогов: «Эхо ×N»; счёт снижается на 15 % за каждый откат; бейдж **«Ни одной свечи»** за победу без откатов.

## 7. Визуал

- Камень Памяти — высокий менгир с вырезанными именами; на нём загорается **свеча** за каждый сохранённый Отпечаток.
- Экран поражения: вместо мгновенного «Game Over» — гаснущий хор, свечи Реквиема на полу; кнопка с огоньком.
- Возврат — короткая сцена «эхо»: силуэт героя поднимается у камня, на нём проступает выбранный Шрам (рубец, тень, пустой кошель).

## 8. Техническая заметка

- Снимок: на хуке `AfterActEntered` (после закрытия стартового узла) копируем файл сохранения забега
  (`current_run.save` / `current_run_mp.save` через `RunSaveManager`) в папку мода как `requiem_act_<n>.save` + JSON с метаданными
  (свечи, шрамы, зерно акта).
- Экран поражения: патч `NGameOverScreen` — кнопка и выбор Шрама.
- Возврат: записать снимок обратно как сохранение забега, изменить зерно карты акта, загрузить забег штатным путём «Продолжить».
- Риски: миграции схемы сохранений между патчами EA (проверяем версию схемы; при несовпадении — откат недоступен с понятным сообщением),
  синхронизация в коопе.

## Статус реализации (этап 3.5, код без сборки)

- **Отпечаток** — `Rollback/MemoryStone.cs`: на `AfterActEntered` (хук служебной реликвии «Свечи Реквиема») снимается
  `RunManager.ToSave(null)` — тот же `SerializableRun`, что пишет «Сохранить и выйти». Хранится JSON-ом в памяти и копией
  `saves/requiem_memory_stone.save` в папке профиля (переживает перезапуск игры). Отпечаток опознаётся по зерну и времени
  старта забега; при другой версии схемы сохранения возврат не предлагается.
- **Экран поражения** — постфикс `NGameOverScreen.AfterOverlayOpened`: при поражении, если есть Отпечаток и Свечи, — окно
  «Вернуться к Камню Памяти?», затем выбор Шрама из трёх карт (локальный экран выбора, пропуск = отказ).
- **Возврат** — штатный путь «Продолжить»: `CleanUp → RunState.FromSerializable → SetUpSavedSingleplayer → NGame.LoadRun`,
  после загрузки переносятся счётчики (Свечи, откаты, Шрамы) из погибшей попытки, накладываются Шрамы
  (`MemoryStoneRules.ScarsToApply`: повторный возврат к тому же Камню повторяет прежние), забег сразу сохраняется.
- **Свечи** — `MemoryStoneRules.CandlesFor`; пока нет уровней «Реквием» (этап 7), уровень = Возвышение забега. Настройка
  «Свечи Реквиема»: −1 — по уровню, 0…9 — своё число.
- **Шрамы** — плоть (−6 % макс. ♥), душа (проклятие «Предсмертное эхо», вес 2 как у всех проклятий), кошелёк (−40 % золота).
- **Месть** — +10 % урона героя по монстрам и фракциям того боя, где он погиб, до конца повторной попытки этого акта.

## Статус реализации (этап 3.6: кооп и новая карта, код без сборки)

- **Единый путь возврата.** Отпечаток дописывается итогами погибшей попытки прямо в свойствах «Свечей Реквиема» каждого игрока
  (`SavedProperties.Fill/From`): общие Свечи, откаты, Шрамы, Месть, `MapRerollAct1` и отложенные Шрамы `Pending*`; карта
  текущего акта из Отпечатка удаляется. Шрамы накладываются после загрузки в `AfterMapGenerated` (карта генерируется при
  любой загрузке — одинаково на всех машинах коопа).
- **Новая карта** — без сохранённой карты акт строит её заново, а `MemoryStoneRelic.ModifyGeneratedMap` подменяет её на
  `StandardActMap` с зерном `act_N_map_requiem_R` (R — номер отката). Босс прежний — он в наборе комнат акта, не в карте.
  Набор боёв/событий акта тоже из Отпечатка — меняется расположение узлов.
- **Кооп** (`Rollback/CoopMemoryStone.cs`, сообщения `MemoryStoneMessage` через BaseLib `ICustomMessage`): Отпечаток снимает
  только хост. На экране поражения хост предлагает возврат → клиенты голосуют (45 с; молчащие не считаются) → большинство
  «за», ничья — решает хост → каждый выбирает свой Шрам (60 с, иначе «Кошелёк») → хост собирает снимок, записывает его как
  сохранение кооп-забега (`IncrementNumReloads`), все выходят в меню; хост сразу открывает лобби загрузки
  (`NMultiplayerSubmenu.StartHost`), клиентам открывается «Присоединиться к другу». Если лобби не соберётся — «Мультиплеер →
  Загрузить» продолжит с Камня.
- **Свечи отряда** — общие: остаток = минимум по Камням, возврат ставит всем одинаковый счётчик потраченных (максимум + 1).
- **Отложено:** Слава 50 % и намерения босса на ход вперёд (этап 5), −15 % счёта и бейдж «Ни одной свечи» — сделаны на этапе 6 [к] (Rollback/RunScore.cs),
  супербосс и «Свеча в склепе», визуал (менгир, сцена «эхо»), автоматическое переподключение клиентов (сейчас — экран
  «Присоединиться к другу»).
