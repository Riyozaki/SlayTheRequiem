# 12. Словарь: источник → мод

Правило: в игре — **только названия из правой колонки**. Левая колонка — для разработчиков, чтобы понимать происхождение идеи.
Английские ключи — для `localization/eng/*.json` и ID в коде (`STR_` префикс мода).
