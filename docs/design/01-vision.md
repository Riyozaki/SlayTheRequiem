# 01. Видение и принципы

## Питч

> Шпиль запел **Реквием** — песнь конца, которую Древние держали взаперти. Её эхо подняло из глубин
> курганных мертвецов, заводных стражей и крылатых тиранов, а самих восходящих научило чувствовать
> усталость, жечь ману и тащить на себе всё, что они решились нести.

**Slay the Requiem** — крупный оверхол StS2, превращающий забег в «хардкорное RPG-восхождение»:
каждый удар стоит сил, каждая карта и железка весят, стихии ведут себя по-разному,
а враги приходят с бронёй, ядами, аурами и фазами.

## Столпы дизайна

1. **Тело — ресурс.** Энергия решает, *сколько действий*, выносливость — *сколько ударов и насколько сильных*,
   мана — *сколько магии*. Все три можно отнимать у врага и враг может отнимать их у вас.
2. **Груз — это выбор.** Колода и снаряжение конечны: всё имеет вес. «Брать всё подряд» больше не стратегия.
3. **Стихия — это механика, а не цвет урона.** Огонь, холод, разряд, яд, хворь, кровотечение и свет
   работают по-разному и имеют ответы.
4. **Враг — это сборка.** Фракция + архетип + стихия + снаряжение + аффиксы. Каждый элитник читается
   и требует плана, а его снаряжение можно забрать.
5. **Решения с ценой.** Знамение — раз за забег. Дары Князей Бездны — с Ценой. Трансформации — с минусами.
   Праведность — с ограничениями.
6. **Читаемость прежде всего.** Каждое правило формулируется одной строкой на карте/иконке.
   Никаких скрытых процентов: состояния ступенчатые (Бодр / Устал / Изнурён), шансы — счётчики.

## Принципы адаптации (как мы переводим Skyrim → StS)

| Skyrim / RFAB | Перевод в StS |
|---|---|
| Секунды, длительности | ходы, «до конца боя», «на N боёв» |
| Шанс X % | счётчик «каждый N-й раз», или детерминированное условие |
| Регенерация/сек | прирост ресурса в начале хода |
| Проценты урона 20 % | плоские +1…+3 к урону/блоку, либо ступени 25/50/75 % |
| Скрытность | «первый ход боя», «из невидимости», удары по цели без намерения атаки |
| Кражи | действия в магазине/событиях, влияющие на праведность |
| Открытый мир, квесты | события «?», цепочки событий через акты, условия-обеты |
| Уровни 1–100 | короткая прогрессия забега: Слава → Уровень 1–10 |
| Сотни видов оружия | ~11 типов оружия × уровни материалов + уникальные |
| Ингредиенты (сотни) | 3–4 типа реагентов + редкие компоненты |

## Сеттинг и нейминг

- **Никаких имён из TES в игре.** Термины источника остаются только в документации (столбец «источник»).
  Полный словарь — [12-glossary.md](12-glossary.md).
- Имена строятся из лексики Шпиля StS: Древние, Нео, восхождение, акты, «Шпиль», «Сердце».
- Тон — мрачно-ироничный, как у StS: короткие ёмкие названия, без пафосной высокой фэнтези.
- Языки: **русский — основной**, английский — второй (локализация StS2 — JSON, поддерживаем оба с первого дня).

## Что мы *не* делаем

- Не делаем «Скайрим в карточках»: нет открытого мира, крафта брони из слитков, торговли за септимы.
- Не ломаем базовые карты StS2: все ванильные карты работают в моде за счёт автоматических правил
  (цены в выносливости/мане, вес по редкости, типы урона по умолчанию).
- Не добавляем механики, которые нельзя объяснить на одной иконке.
