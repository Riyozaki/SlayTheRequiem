# Технический план

## 1. Стек

| Компонент | Выбор | Примечание |
|---|---|---|
| Язык | C# (`net9.0`) | компиляция против `sts2.dll` из папки игры |
| Движок | Godot 4.5.x (модифицированный «MegaDot») | ресурсы пакуются в `.pck` |
| Патчинг | HarmonyX (встроен в загрузчик модов StS2) | префиксы/постфиксы на методы игры |
| Библиотека | **BaseLib** (Alchyr) | базовые классы карт/реликвий/сил/персонажей, автрегистрация, конфиг-UI, кастомные ключевые слова |
| Шаблон | `Alchyr/ModTemplate-StS2` | структура `Code/{Cards,Relics,Powers,Potions,Monsters,Encounters,Events,Characters,Patches,UI}` |
| Локализация | `localization/eng/*.json`, `localization/rus/*.json` | ключи с префиксом `STR_` |

Проверенная версия игры для старта — та, на которой собирается шаблон (EA ≥ 0.103). В `mod_manifest.json` указываем минимальную версию; при каждом патче EA — прогон смоук-тестов.

│  └─ UI/                    шкалы ◆/✦, экран снаряжения, лагерь, груз

## 3. Ключевые системы и точки интеграции

| Система | Как реализуем | Риск |
|---|---|---|
| **◆/✦ шкалы** | компонент на `Creature`/`Player` (через Harmony-постфикс конструктора или BaseLib-хук «combat start»); UI — дочерний узел к полоске ♥ | средний: UI игроков в коопе |
| **Цена карт в ◆/✦** | атрибут/интерфейс `IResourceCost` на карте + патч `CanPlay` и `OnPlay`; ванильные атаки — правило по умолчанию из конфига | **высокий**: все ванильные карты, X-карты, авто-розыгрыш (Sly) |
| **Типы урона и сопротивления** | `DamagePipeline`: патч на расчёт итогового урона (после Силы/Слабости, до Блока) → тип, Латы, Пробитие, сопротивления | высокий: порядок модификаторов с ванильными Уязвимостью/Хрупкостью |
| **Статусы** | наследники BaseLib Power; ключевые слова — CustomEnum | низкий |
| **Ошеломление/Слом** | Power «Шаткость» + патч на выбор намерения врага (отмена текущего Move) | средний: AI-машины монстров |
| **Снаряжение** | `EquipmentItem : CustomRelic` + слот; Loadout — сохраняемое состояние в save-файле забега | средний: сериализация сейва |
| **Груз** | вычисляемое значение по колоде + Loadout; патч экрана наград (вес рядом с картой) | низкий |
| **Знамения/Небесные/Князья** | реликвии-«благословения»; Нео-дар — патч пула опций Нео; Святилище — новый тип узла карты | средний: генерация карты |
| **Трансформации** | Power-«Сущность» + подмена спрайта персонажа | средний: визуал |
| **Лагерь** | патч `RestSite`: свои `RestSiteOption`, очки лагеря | средний |
| **Враги** | BaseLib-монстры + аффиксы как Power, накладываемые при спавне | низкий |
| **Супербоссы** | дополнительный `Encounter` в узле после босса; объекты на поле — монстры-«пропсы» | средний |
| **Кооп** | все состояния — на уровне игрока, синхронизируются через существующие сетевые действия игры | **высокий**: проверять рано |

## 4. Данные

- Баланс в `data/*.csv` (предметы, аффиксы, враги, рецепты) → генератор `tools/gen` создаёт C#-партиалы и JSON локализации.
  Геймдизайнер правит таблицы без перекомпиляции логики.
- Стабильные ID: `STR_<Тип>_<Имя>` (например, `STR_RELIC_EVERICE_HAMMER`). Не менять после релиза — ломает сейвы.

## 5. Конфиг мода (BaseLib config UI)

- Модули (вкл/выкл): Выносливость, Мана для не-Регента, Груз, Снаряжение, Реакции стихий, Усталость похода, Супербоссы, Метапрогресс лагеря.
- Множитель ♥ врагов (0.8–1.5), уровень «Реквиема» по умолчанию.
- Модульность — главное средство против риска: каждая система тестируется отдельно и выключается при поломке после патча EA.

## 6. Тестирование

1. **Юнит-тесты** (xUnit, без движка): DamagePipeline, тики статусов, груз, цены ресурсов, Слом.
2. **Смоук-сцены:** debug-консоль игры + команды мода (`str_give <id>`, `str_fight <encounter>`, `str_stat`).
3. **Симуляция баланса:** Python-скрипт в `tools/sim` — Монте-Карло урона колод против врагов по таблицам `data/` (быстрая проверка «Горение vs Яд», «Латы vs многоудар»).
4. Плейтест-чек-листы для каждой вехи (ROADMAP).

## 7. Арт

- MVP: иконки статусов/предметов 64×64 и 128×128 в стиле StS (толстый контур), портреты происхождений — перекраска ванильных моделей.
- Позже: спрайты форм (вампир/оборотень/лич), куклы снаряжения, супербоссы.
- Генерация концептов допустима, финальные ассеты — ручная доработка под стиль игры.

## 8. Риски

| Риск | Митигирование |
|---|---|
| Патчи EA ломают сигнатуры | тонкий слой `Patches/`, по файлу на систему; CI-сборка против свежей `sts2.dll` |
| Перегрузка интерфейса (3 шкалы + груз + слоты) | модули, обучающие подсказки, MVP только ◆ |
| Баланс ресурсов | `tools/sim` + конфиг множителей |
| Совместимость с другими модами | префикс ID, не заменять ванильные классы, только хуки |
| Объём контента | вертикальный срез сначала (ROADMAP, Этап 1) |
