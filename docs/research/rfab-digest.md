# Выжимка источника: библиотека RFAB (skyrimrequiem.ru/pages/library)

Источник — одна большая страница-справочник (37 текстовых блоков) плюс отдельные страницы боссов.
Ниже то, что изучено, **что из этого важно для механик** и как это читается в терминах StS.

> **Пробелы в данных.** Карточки экипировки и заклинаний на сайте подгружаются скриптом:
> в тексте страницы есть только *названия* (≈300 видов оружия, ~100 наборов брони, ~150 украшений,
> ~170 заклинаний), уровни наборов брони (I–V) и полные значения зачарований. Цифры конкретных
> предметов и заклинаний получить не удалось — для дизайна они и не нужны (статы мы не копируем),
> но если понадобятся, лучше выгрузить их из файлов мода/с сайта отдельно.

## 1. Общие правила сборки (FAQ)

| Что в RFAB | Суть | Вывод для мода |
|---|---|---|
| Сложности Странник / Довакин / Легенда + флаг «Проклятый» | множители входящего/исходящего урона | Режимы «Реквиема» поверх Возвышения (см. ROADMAP) |
| Один Камень-Хранитель **на всю игру** | крупный пассив, выбор раз и навсегда | **Знамение** — выбирается один раз за забег у Нео |
| Предыстория у каждой расы (3 шт.) + универсальный «Бродяга» | стартовые навыки, заклинания, предметы | **Предыстории** = вариант стартовой колоды/реликвии |
| Опыт за убийства/квесты, 1 очко навыка и 5 статов за уровень | пороги статов дают бонусы | Лёгкая прокачка внутри забега: **Слава → Уровень** |
| Порядок врагов: бандиты → изгои/маги → фалмеры → двемеры → драугры → вампиры/драконы → жрецы → супербоссы | кривая сложности по фракциям | Фракции по актам StS2 (см. 11-enemies) |
| Капы: яды/болезни 100 %, магия/стихии 75 %, броня 80 % физ. снижения | жёсткие пределы | Сопротивления ступенями по 25 %, кап 75 % |
| **Устойчивость** 25/50/75/100 % — защита от ошеломления | ошеломление прерывает атаку | **Стойкость** и механика **Ошеломления** (сбивает намерение) |
| Броня (0.1 % за ед.) vs **пробитие брони** | дуэль статов | **Латы** (плоское снижение каждого удара) vs **Пробитие** |
| Числовая регенерация действует всегда, процентная — с условиями | разные виды реген | Реген ресурса по ходам; «ломается» эффектами |
| Защищённый общий сундук | склад вне инвентаря | **Сундук лагеря** — хранение сверх груза |
| Лошадь даёт переносимый вес | | **Вьючный зверь** — апгрейд лагеря |
| Еда/алкоголь: активен один эффект | | **Особая еда** — один бафф на N боёв |

## 2. Расы (10) и их отличия

Базовые статы различаются: ХП 100–150, СТ 50–150, МП 50–150; реген СТ 1.25–2 %, МП 1–2 %;
переносимый вес 150–250. Расовые пассивы (как они читаются в моде):

| Раса | Пассив RFAB | Механический смысл |
|---|---|---|
| Орк | «Ярость»: −25 % урона во время атаки/каста | награда за агрессию |
| Норд | 25 % холод, 15 % ту'ум | живучесть против холода, голос |
| Редгард | «Ритм пустыни»: реген СТ растёт при низкой СТ; 50 % яд | «второе дыхание» |
| Каджит | иммунитет к скуме, падению, ночное зрение, кулаки 50 | ловкач, безоружный бой |
| Босмер | звери не нападают первыми; 50 % болезни | первый ход против зверей |
| Альтмер | +50 МП, −10 % цена заклинаний, −15 % сопр. магии | стеклянная пушка |
| Бретонец | 15 % сопр. магии, 15 % поглощение заклинаний | анти-маг |
| Данмер | 25 % огонь, «Предтечи Трибунала» — доступ к трём даэдрическим благословениям | даэдрический путь без условий |
| Имперец | +5 базовых статов каждые 5 уровней; +50 СТ | масштабирование |
| Аргонианин | «Кора хиста»: реген ХП растёт при низком ХП; яд/болезни | регенерация на грани |

**Предыстории** (по 3 на расу, итого 30 + Бродяга): Берсерк, Браконьер, Шаман; Воитель Кин, Бард,
Заклинатель хлада; Эш'аба, Заговорщик, Ансей; Беглый раб, Плут, Сумеречный певец; Танцующий с ветром,
Охотник, Отшельник; Юстициар, Чародей теней, Волшебник; Рыцарь, Зачарователь, Колдун; Ординатор,
Эшлендер, Ученик Телванни; Легионер, Посол, Маг империи; Гладиатор, Тёмный ящер, Отравитель.
Каждая — 3 врождённых навыка + уникальная деталь (аура против сопротивления, бесплатное поддержание
заклинания, спутник, особый эликсир, похлёбки, призыв духа зверя и т.п.).
**Вывод:** предыстории — готовые архетипы колод; их «уникальная деталь» = стартовая реликвия/карта.

## 3. Камни-Хранители (10 основных + 6 «солстхеймских»)

Основные (бонусы без штрафов, выбирается один на игру):
1. **Воин** — +ХП, реген ХП/СТ, +20 % физ. урона, +10 % скорость атаки, *низкая СТ не режет урон*.
2. **Лорд** — 15 % магия, 25 % все стихии, 15 % стрелы, +100 брони, 100 % устойчивости, броня за устойчивость сверх 100 %.
3. **Маг** — +МП, аура −15 % сопр. магии врагам, скорость каста, реген МП, −10 % цена, *низкая СТ не дорожит заклинания*.
4. **Атронах** — +100 МП, 15 % поглощение, 10 % урона в ману, **реген маны ×0.5**.
5. **Ритуал** — −20 % цена колдовства, +1 призыв, бесплатные некро-ауры.
6. **Конь** — +СТ, +250 веса, иммунитет к параличу/заморозке/шоку, минимальная цена ударов в СТ.
7. **Вор** — карманные кражи на виду, продажа краденого.
8. **Голос** (ту'ум) — урон боевого ту'ума, перезарядка, сопр. ту'уму, торговцы на уровень выше.
9. **Тень** — бесшумность, скрытность, невидимость в тени.
10. **Змей** — +25 % урона ядами, 25 % сопр. ядам, аура −25 % сопр. ядам, 5 зарядов яда на оружии.

«Солстхеймские» камни (бонус + **штраф**): Земля (+СТ, +броня, −скорость), Дерево (магия, яды, −огонь),
Зверь (+урон, +пробитие, −10 % физ. сопр.), Вода (+МП, реген, −электричество), Ветер (скорость атаки и бега, −броня),
Солнце (+ХП, реген, −холод).
**Вывод:** основные → *Знамения* (раз за забег); солстхеймские → *Осколки отлива* (событие с компромиссом).

## 4. Боги (аэдра) и праведность

Условия праведности: <10 краж, не в Гильдии воров и Тёмном Братстве, ни одного убийства мирных,
нет даэдрических предметов, не вампир/оборотень/лич.
Благословение бога + его **амулет** (бонус при благословении; второй бонус — с перком «Безупречная праведность»)
+ **одеяние/броня бога** + перк «Небесный щит» = **Дух божества** (сетовый бонус).

| Бог | Благословение (суть) |
|---|---|
| Акатош | СТ, сопр. ту'уму, огонь |
| Зенитар | ХП, реген СТ, урон силовых атак |
| Джулианос | МП, реген МП, сопр. магии |
| Дибелла | реген МП, дешёвая иллюзия, поглощение заклинаний |
| Кинарет | реген всего, колющее оружие, яды, падение |
| Мара | реген ХП, дешёвое восстановление, болезни, иммунитет к параличу |
| Аркей | броня, стрелы, холод, иммунитет к заморозке (не с некромантией) |
| Стендарр | скорость атаки, урон по нежити/даэдра, скорость бега (не с некромантией) |
| Талос | урон ту'ума, перезарядка, электричество |
| Ауриэль | маг. урон по нежити/даэдра при атаках, аура ослабления нежити |

## 6. Ветки (мировоззрение, герой, выживание, репутация)

- **Оборотень**: Дар → Звериная мощь (ур.10) → Неукротимая воля (20) → Обузданный зверь (30, «второе дыхание»).
  Форма зверя: огромные ХП/броня/когти, длительность продлевается ударами, кулдаун; **тотемы** (Охота/Страх/Братство) с воями.
  Артефакты-комплекты (кольцо+амулет → бонус в форме).
- **Вампир**: Заражение → Багряное проклятие → Неутолимый голод → Древняя кровь → форма Лорда.
  Сильные плюсы + жёсткие минусы (−огонь, серебро, нет лечения и еды, нет света). Комбинации артефактов (кольцо+амулет → «Каменная форма»).
- **Слуга Повелителей**: Тёмный пакт (убийство мирного) → Вестник смерти (3 стойки) → Лик тьмы (**лич**: ауры, всплеск тьмы, взрыв смерти при 50 % ХП).
- **Чемпион Богов**: Безупречная праведность (аура восстановления) → Священная мощь (аура силы) → Запечатанная решимость / Длань возмездия (3 кары) / Небесный щит.
- **Путь Героя** (40 ур., требования по навыкам): Паладин, Чёрный страж, Чемпион, Варвар, Стрелок, Застрельщик, Ассасин, Вор, Монах,
  Губитель, Мистический стрелок, Жрец, Испепелитель, Стужевик, Громовержец, Элементалист, Кинетик, Боевой маг, Воин-маг, Медиум,
  Отражатель, Переродившийся.
- **Выживание**: Кулинар, Гурман, Бодрость, Акклиматизация, Ведение боя, Основы выживания (двойные ингредиенты, −урон от зверей),
  Охотник глубин / Расхититель гробниц / Убийца чудовищ (−урон от фракции).
- **Репутация**: ассортимент торговцев, эффективность торговли.

## 7. Алхимия

- **Зелья** I–III (+превосходные): восстановление (реген в секунду, 20 с), запас (ХП/МП/СТ + % регена, 300 с),
  защита (магия/огонь/холод/электричество), комбинированные (Омоложение, Гармония, Стихии), утилитарные
  (Перышко — вес, Тень — невидимость, Панацея, Противоядие, Иммунитет, Свёртывание крови, Кабан — скорость,
  Великан — устойчивость, Рыцарь — броня, Коагуляция, Заклинатель, Атронах, Бодрость, Адреналин, Воитель, Мастер).
- **Яды** I–V: прямой урон, периодический, комбинированный, **парализующий**; превосходный.
- **Токсины** I–V: то же, но урон **болезнью** (обходят сопротивление ядам).
- Крафт: 3 экстракта (I+I+II и т.д.), рецепты находятся в мире; заряды яда на оружии.
- **Настои**: навсегда +статы, +реген, +сопротивления, +очко навыка.

## 8. Заклинания (по названиям)

- **Разрушение**: искры (поток), стрелы, «дух», «клинок», снаряд, **руны**, **плащи**, **новы**, лучи, заморозка/надлом,
  цепная молния, вампирические заклинания, ультимативные (Апокалипсис, Триумвират, Инферно, Буран, Каскад молний, Статический купол…).
- **Восстановление**: лечение, обереги, медитация, **солнечные** (против нежити) и **ядовитые** заклинания, священное оружие, круги.
- **Изменение**: магическая броня, паралич, поглощение СТ/МП, **телекинез** (импульс, столп, взрыв, метеор), трансмутации, полиморф, увядание.
- **Колдовство**: ауры призыва, призыв роя/волка/скелетов/дремор/атронахов/трэллов/колосса, **призванное оружие I–V**, некролечение, взрыв трупа, изгнание даэдра.
- Школы имеют перки «Мастер рун», «Повелитель стихии» (переключаемая аура: +сопр. себе ИЛИ −сопр. врагам), «Кремирование/Глубокая заморозка/Разряд» (на высоком уровне поджигают/замораживают/ошеломляют).

## 10. Таланты и пороги статов

- **Пороги базовых статов** (каждые 25 после 225 → бонус; 500 → особый): ХП → сопр. ядам/болезням + вес, «Стальная решимость»;
  МП → скорость каста + реген, «Единение» (урон в ману); СТ → физ. урон + реген, «Проворность».
  **Вывод:** вложение в стат должно открывать *ступени* с качественными бонусами.
- Квестовые таланты: −урон от фракции, +урон по типу врага, активные способности с перезарядкой (невидимость, иммунитет к магии, двойники…).

## 11. Экипировка (по названиям и уровням)

- Оружие: одноручные мечи, топоры, булавы, кинжалы, копья, двуручные мечи/секиры/молоты, боевые посохи, магические посохи, луки, арбалеты.
- Броня — **наборы уровней I–V** по трём классам: *тканевая (тени)*, *лёгкая*, *тяжёлая (воитель)*; пары чисел защиты по уровню
  (15/25, 30/50, 45/75, 60/100, 75/125, 90/150 — лёгкая/тяжёлая).
- Уникальные части (маски драконьих жрецов, перчатки, сапоги, короны), магические книги/щиты для левой руки.
- Бижутерия: базовые кольца/ожерелья/обручи с одним свойством (ХП, СТ, МП, тролль, передышка, концентрация, сопротивления,
  рыцарь, атронах, каменная кожа, великан, заклинатель, воитель, мастер, саблезуб, тень, разрушитель оков, школы магии)
  + ~50 уникальных, часть работает **комплектами**.
- Зачарования: ХП/СТ/МП +50, скорость 10 %, скорость атаки 10 %, каст 20 %, −10 % цена, +100 брони, свобода движения,
  15 % стрелы, 25 % устойчивость, сопротивления, скрытность/бесшумность, реген, +20 % физ. урона, +100 пробития и т.д.
- Свитки и посохи — расходники/заряды; посохи создаются из камней душ и самоцветов.

## 12. Что берём, что нет

**Берём:** ресурсы тела и их взаимодействие со стихиями; стойкость/ошеломление; броня vs пробитие; классы брони;
типы оружия с перками; слоты и комплекты бижутерии; уровни снаряжения; алхимию с ядами и токсинами;
выбор камня раз за игру; пантеон и праведность; трансформации с тяжёлыми минусами; лагерь; аффиксы и фазы боссов.

**Не берём / сильно меняем:** реальное время (секунды → ходы), проценты-шансы (→ детерминированные счётчики),
скрытность и кражи как отдельные системы (→ точечные механики первого хода/магазина),
открытый мир, крафт с десятками ингредиентов (→ 3 типа реагентов), все названия.
