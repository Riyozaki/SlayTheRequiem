# Slay the Requiem — дизайн-документация

Мод на **Slay the Spire 2** (Early Access, Godot/C#), вдохновлённый сборкой Skyrim RFAB/Requiem.
Цель — не перенос Скайрима в Шпиль, а **перевод его идей на язык карточного рогалика**:
ресурсы тела (выносливость, мана, груз), стихии с разной механикой, снаряжение со слотами,
алхимия с ядами, пантеон и праведность, трансформации, лагерь и куда более злые враги.

## Статус

Этап: **детальный план готов** (все документы из таблицы написаны), кода пока нет. Следующий шаг — Этап 0 из [ROADMAP](ROADMAP.md).

а не перенос цифр из Skyrim. Всё подлежит плейтесту.
