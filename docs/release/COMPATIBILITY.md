# Совместимость, saves и config

**Контракт кандидата, не сертификат уже выполненной приёмки.** Историческая сборка/PCK и плейтест пользователя
на `ec598de` были успешными; новые Б1–Б3 требуют собственной полной сборки и финальных клиентов.

| Компонент | Требование / текущая версия |
|---|---|
| Игра / native references | **0.107.1**; другое обновление требует отдельной проверки API, saves и ресурсов |
| BaseLib | **3.4.8** при сборке и в первом приёмочном клиенте; более новая версия пока не сертифицирована |
| .NET SDK / MegaDot (сборщик) | **9.0.x / 4.5.1 mono**; ModAnalyzers **0.2.1** |
| Session handshake | **5**; старый 4 / будущий 6 должны отклоняться до совместного старта |
| Creation journal / save schema | **2 / 4** |
| Shop operation protocol / economy revision | **2 / 1** |
| RunSettings envelope | **v1**, сохранён; это не номер session protocol |
| HeroCreationPlan / отдельные ledgers | Имеют собственные версии; их `1` не означает session 1 или save 1 |

Не повышать protocol/schema только ради исправления устаревшего README. Числа сверяются инструментальными тестами
между runtime, csproj AssemblyMetadata и G0. Сам manifest пока `v0.0.1`; идентичность кандидата — полный source/input hash
и hashes DLL/PCK/JSON. В коопе сравнивать их, а не только version string.

## Другие моды и кооп

Первая полная матрица — только **BaseLib + SlayTheRequiem**. Другие моды, меняющие damage/piles/rewards/starting deck,
сериализацию, боевой UI, выборы и multiplayer, могут перехватывать те же hooks. Список «совместим со всеми» не заявлен.
Дополнительную совместимость фиксировать с точными версиями/DLL hashes, отдельно от обязательного baseline.
Разные локальные параметры оформления допустимы; игровые правила берутся из сохранённого host snapshot.
Личные origin/background остаются личными. Все участники обновляют комплект одновременно; отказ negotiation —
не повод обходить Ready или отправлять unknown custom-message types старому BaseLib.

## Старый config

- Новая установка по умолчанию предлагает выбор происхождения/предыстории. Старые явно сохранённые `Random`/выборы
  не должны молча перезаписываться. Их поведение и сохранение настроек BaseLib ещё проверяются финальными сценариями.
- `ReducedMotion`, VFX, звук, compact statuses — **локальное оформление**, не часть RunSettings wire/save envelope.
  Reduced motion выключает добавочное движение/мигание мода, не обещает остановить всю native-анимацию игры.
- Выключение систем посреди уже созданного run не является миграцией его правил. Смену игровых defaults проверять
  на новом run, а не переписывать snapshot старого под текущий config.

## Старые saves и неизвестные данные

Перед любым Continue — отдельная копия профиля. Поддерживается только явно реализованный legacy-путь **mod metadata
в совместимом native формате игры**. Это не обещание загрузить все сейвы всех версий игры/мода.

Strict preflight сохраняет raw original/backup до изменения; неверные типы, duplicate/unknown поля и неподдержанная
native schema отвергаются без native aggressive repair/rename. Missing primary может использовать native backup,
но существующий повреждённый primary не подменяется молча старым. Foreign/future contracts или противоречивые snapshots
не заменяются локальным меню/defaults. После отказа использовать matching build или известную целую копию хоста.

Legacy-завершённое создание не должно заново дарить HP/школы/карты. Завершённый источник Пути не выдаёт ещё один Знак
после намеренной потери. `Reborn` меняет identity и возвращает только оплаченные характеристики/снятое платное владение;
навыки, трактаты и добыча сохраняются, одноразовые подарки не повторяются. Эти правила имеют source/Core проверки,
а disk Continue/реальные adapters остаются обязательной финальной приёмкой.

## Recovery — не ручной unlock

`OperationPending` / `OperationBlocked` сохраняют неопределённый результат. **Не удалять эти поля, не повторять оплату,
не менять revision/timeline руками.** Receipt retry сверяет исходный request/receipt; partial commit не очищается
новым кликом. Без согласованной квитанции — восстановление целого безопасного run, в коопе через копию/лобби хоста.

Локальные копии могут называться `requiem_inventory_checkpoint[_coop].save`, `requiem_inventory_failed[_coop].save`,
`requiem_before_migration[_coop].save`, `requiem_before_load[_coop].save` и `.previous`/native-backup вариантом.
Это **приватные пользовательские данные**, не файлы релизного архива. Rollback меняет целый timeline, а не только кошелёк.
Downgrade не мигрирует save назад автоматически.
