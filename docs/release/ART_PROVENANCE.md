| Область | Исходники и runtime | Решение / ещё открытая приёмка |
|---|---|---|
| Шесть сцен карт | `art/illustrations/manifest.json`, `masters/*.png` → `images/card_portraits/[big/]` | ShieldBash, Backstab, ArcaneFocus, Firebolt, Whirlwind, FocusedAim; рисунок показывает разные действия, не общий шум/свечение |
| Король, обе фазы | `sprite-manifest.json`, king masters → `images/monsters/king_under_barrow[_p2].png` | 440×520 RGBA, земля/вписывание; p2 сделана с retained base reference |

| Карта | `art/readable-icons.json`, `art/map/icons/*.svg` → 20 PNG + 20 outline masks | Силуэты читаются отдельно от цвета, карта сохраняет штатную подсветку/material |
| Лагерь | тот же receipt, `art/ui/rest_site/*.svg` → 14 PNG | Категории/действия различимы; полный runtime OptionId, не обрезанный id |

Мастера — AI-generated outputs инструмента генерации, без внешних изображений на входе. Единственные image references
для двух производных — их сохранённые generated bases. Prompts/reference-chain/hashes и ограничения записаны в manifest
и `quality-prompts.json`. **Это не детерминированная регенерация AI-изображения, не exclusive copyright, не новая
распространительная лицензия и не одобрение пользователя.** Воспроизводимы crops/resize/matte/flip/fit и финальные pixels.
Исходные PNG не заменяются автоматически новыми generations. Blanket SVG renderer защищает promoted raster от затирки.

## Что намеренно не перерисовано этим пакетом

- Настоящие ванильные стартовые Strike/Defend/геройские карты сохраняют **собственный native арт**, чтобы не превращать
  один и тот же игровой тип в две случайные идентичности. Мод ссылается на установленную игру, не копирует её PNG.
- ShieldBash/Backstab — частые common-карты; первая также доступна через Legionary. ArcaneFocus и Firebolt входят
  в новый базовый старт Регента. Whirlwind/FocusedAim — эталоны Путей, **не** заявлены стартовыми всех героев.
  Spirit Wolf и остальные исходные стартовые/предысторические изменения отдельно видны в CSV и проверяются в игре.
- Для остальных собственных карт/сил/части реликвий/зелий выбран конкретный native portrait/icon по
  `tools/art/vanilla_art.csv`, VanillaArt/LookOf/FallbackIcon. Причины исключений типа/дубля — в `note` таблицы;
  `art_fit.py --check` проверяет тип карты и столкновение с видимыми ванильными пулами/значками.
  Это **согласуемое fallback-покрытие**, не заявление, что новая картинка уже нарисована и принята.
- Старые собственные боссы/сцены/события/экипировка имеют SVG-генераторы под `tools/art/` и редактируемые `art/`.
  Они сохранены, а не скрыто заменены generic hatch. Часть ещё не оценена по новому эталону в игре: статус **OPEN**.
- Перечень каждого ожидаемого model/UI path и фактического own/vanilla/missing —
  [`asset-coverage.csv`](asset-coverage.csv) в репозитории. Extra phase/form mappings — в sprite manifest.
  `own` означает наличие своего файла, **не** художественное качество/права/PASS. Нет blanket-освобождения от приёмки
  для оставшихся fallback: владелец должен подтвердить их осмысленность, иначе заменить затронутые slots до выпуска.

Проверки не принимают молчаливый `nope` или template за дизайн. `Exists`, размер/альфа/правильный hash не доказывают
путь, который фактически загрузился в клиенте. Жалоба `nope` остаётся отдельным воспроизведением с ID/runtime path.
Контактные листы — source previews, не игровые скриншоты/голос автора.

## Звук

`mod/SlayTheRequiem/data/sfx.csv` задаёт слои. 7 собственных WAV синтезируются `tools/audio/build_sfx.py` без внешних
семплов; native FMOD/debug-audio обозначены ссылками на установленную игру и не вшиты в архив как чужие sound banks.
Исходник синтеза/таблицы сохраняется. Проверяются пути событий и соответствие WAV генератору; actual mix, громкость,
серии/пять целей и независимость SFX/VFX/reduced-motion требуют финального прослушивания в клиенте.
